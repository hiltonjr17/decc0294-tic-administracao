O TOP 10 definitivo exige paginar até hasMore=false (limite 1 req/s) e somar va_custo por ds_siorg_n05. O endpoint teto_gastos/baseclassificada?Ano=2025 estava 404 na consulta.

III. Grimório — como reproduzir

❦ Endpoint

GET https://apidatalake.tesouro.gov.br/ords/cdwhprd/custos/tt/demais?ano=2025&limit=1000&offset=0
→ { items:[{ ds_siorg_n05, va_custo }], hasMore, limit, offset }

❦ Agregação PowerShell

$agg=@{}; $off=0
do {
 $j=(Invoke-WebRequest "...&offset=$off" -UseBasicParsing |
  % {[Text.Encoding]::UTF8.GetString($_.RawContentStream.ToArray())})|ConvertFrom-Json
 $j.items | % { $agg[$_.ds_siorg_n05]+=[double]$_.va_custo }
 $off+=1000; Start-Sleep 1
} while($j.hasMore)
